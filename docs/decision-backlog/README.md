# Decision backlog

Questions and findings that need a decision nobody has made yet. Nothing
here is decided. Decisions are in [`../decisions/`](../decisions/README.md).

- **One file per question,** named with a short slug and no number. A
  number is assigned only when the item becomes a decision record.
- **Not a `proposed` record.** An item can be an open question, a half-made
  decision, or facts gathered for a decision still to come.
- **Facts are dated.** Re-check them before acting on them.

| Item | Question |
|---|---|
| [custom-domain](custom-domain.md) | Which custom domain should the Embiggenizer use? |

## Closing one out

- **Decided:** write the record in [`../decisions/`](../decisions/README.md),
  and delete the item and its row in the same commit.
- **Dropped:** delete the item and its row, with a one-line reason in the
  commit message.
